# Deployment and edge course review — 2026-10-14

**Coverage:** all **55 course entries** (`Guide.md` / `README.md`) in Phase 4 Tracks A/B/C and Phase 5 Track C were inventoried and reviewed at entry/topic level. Each now has a distinct integration exercise or a rebuilt connected syllabus. **22 primary source pages** were consulted for the technical corrections below.

**Depth and limits:** This is a targeted technical and pedagogical review, not a claim to have executed or line-by-line certified tens of thousands of lines of existing hardware examples. The depth column distinguishes structural/handoff review from examined technical sections and the fully rebuilt DLA/Gemma courses. Associated Qwen lectures 02–05 received targeted identity/shape and evidence-scope edits; their remaining runtime commands and numerical examples are not fully validated. Existing long Jetson references retain release-specific and illustrative material, explicitly scoped where examined. No Jetson, FPGA, CUDA kernel, radio, or robot performance measurements were run in this review.
