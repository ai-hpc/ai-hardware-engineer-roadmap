01 · Freeze the source

Pause samples. The distance stays on screen, while its age increases and its status becomes stale.

02 · Break the input

While paused, inject a nonfinite distance. The last valid value remains labeled invalid, never fresh.

03 · Start a new session

Disconnect and reconnect. A new session clears the old observation before accepting new data.
