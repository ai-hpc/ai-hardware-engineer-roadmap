# Foundations and embedded course figures

Original technical illustrations created for this curriculum on 2026-10-14. Editable SVGs and PNG exports are generated by `render.py` (Python 3 and CairoSVG). These assets use the repository’s [MIT license](https://github.com/ai-hpc/ai-hardware-engineer-roadmap/blob/main/LICENSE); no third-party image was copied.

- `observation-contract`: conceptual separation between tensor/buffer work and observation freshness, runtime ownership, control validation, and wireless management. This is a teaching architecture, not a vendor block diagram or certified robot design.
- `thread-role-map`: conceptual topology based on [OpenThread node-role documentation](https://openthread.io/guides/thread-primer/node-roles-and-types) and [border-router documentation](https://openthread.io/guides/border-router). Layout and artwork are original.

Regenerate from the repository root:

```bash
python3 Assets/illustrations/foundations-embedded/render.py
```

Each SVG includes a title and description. Markdown pages include descriptive alternative text and a question that directs attention to the relevant boundary.
