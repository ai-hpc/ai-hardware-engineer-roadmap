# Deployment diagrams

`memory-ownership.svg` is an original, editable teaching diagram created for this curriculum; `memory-ownership.png` is its 1800-pixel raster export. No third-party image is embedded. Both inherit the repository license.

The picture explains allocation, layout, ownership, completion, and action freshness. It is conceptual, not a hardware floorplan or measured timing chart. Hardware boundaries are supported by the NVIDIA Orin power tables and software-encode documentation cited in the linked Jetson courses.
